# Levant Massage — Ivan & Marina

Сайт массажного дуэта Ивана и Марины в Валенсии. Статический: HTML/CSS/JS без фреймворков, 4 языка — украинский (`/`), русский (`/ru/`), испанский (`/es/`), английский (`/en/`).

- Прод: https://ivanmarinalevant.vercel.app (ветка `main`).
- Старая версия (до пересборки): https://ivan-marina-levant-v1.vercel.app (ветка `v1`, заморожена).

## Как устроено

```
site/                    ← готовый сайт, его раздаёт Vercel (без сборки)
  index.html, ru/, es/, en/
  assets/css/site.css    ← дизайн-система (см. DESIGN.md)
  assets/js/site.js      ← занавес, партитура 4 рук, зоны, запись → WhatsApp
  assets/img, assets/fonts
tools/
  data.mjs               ← контакты, услуги, ЦЕНЫ, длительности, отзывы
  i18n/{uk,ru,es,en}.mjs ← все тексты
  build.mjs              ← генерирует страницы в site/
materials/               ← посты Instagram, бриф, исследование ниши
```

После правок в `tools/`:

```bash
node tools/build.mjs
```

и закоммитить `site/`.

## Цены

В `tools/data.mjs` у каждой услуги `price: null` → на сайте «ціна після консультації». Поставь число в евро (`price: 70`), пересобери — цена появится в списке услуг и в записи («від 70 €», если длительностей несколько). **Длительности примерные — сверить с мастерами.**

## Запись (демо)

Свободные окна генерируются (стабильно по дате), на сайте это помечено как пример. Кнопка отправки открывает WhatsApp с готовым сообщением: Иван → +34 613 728 778, Марина / оба / «не важно» → +34 613 296 874. Для реального календаря заменить `slotsFor()` и обработчик `submit` в `site/assets/js/site.js`.

## Локальный просмотр

```bash

```
