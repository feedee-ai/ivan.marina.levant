# Levant Massage — Ivan & Marina

Сайт массажного дуэта Ивана и Марины в Валенсии. Статический, без фреймворков: открывается откуда угодно, хостится бесплатно (GitHub Pages, Netlify, Cloudflare Pages).

Языки: **украинский (по умолчанию, `/`)**, русский (`/ru/`), испанский (`/es/`), английский (`/en/`). Каждая версия — отдельная HTML-страница со своими `hreflang`, чтобы Google индексировал все четыре.

## Как устроено

```
src/config.mjs        ← контакты, услуги, ЦЕНЫ, длительности, отзывы, точки на фото
src/i18n/{uk,ru,es,en}.mjs ← все тексты сайта на каждом языке
src/render.mjs        ← разметка страницы (один шаблон на все языки)
build.mjs             ← собирает index.html, ru/, es/, en/
assets/css/style.css  ← дизайн-система
assets/js/main.js     ← запись, «Де болить», canvas «4 руки», мифы, отзывы
assets/img, assets/fonts ← фото (кропы из Instagram) и шрифты (Oswald + Onest, self-hosted)
```

После любых правок в `src/` пересобери:

```bash
node build.mjs
```

Готовые `index.html`, `ru/`, `es/`, `en/` коммитятся в репозиторий — их и деплоим.

## Цены

В `src/config.mjs` у каждой услуги стоит `price: null` → на сайте показывается «ціну уточнюйте». Поставь число в евро:

```js
{ id: 'four', masters: ['both'], durations: [90], price: 120, signature: true },
```

Если у услуги несколько длительностей, цена показывается как «від 55 €». Длительности (`durations`) — тоже там, они используются в записи для расчёта свободных окон. **Длительности сейчас примерные — сверить с мастерами.**

## Запись (демо)

- Свободные окна **генерируются** (псевдослучайно, стабильно по дате) — реального календаря пока нет. На сайте это помечено «демо».
- Кнопка «Надіслати заявку» открывает WhatsApp нужного мастера с уже заполненным сообщением (услуга, мастер, дата/время, имя, телефон, комментарий). Иван → +34 613 728 778, Марина / оба / «не важно» → +34 613 296 874.
- Когда появится база/календарь: заменить функции `busy()` / `slotsFor()` и обработчик `submit` в `assets/js/main.js` на запросы к API (Cal.com, Google Calendar, Supabase и т.п.).

## Что заменить перед запуском

- `site.url` в `src/config.mjs` — реальный домен (для canonical, hreflang, OG).
- Цены и длительности.
- Фото: сейчас это кадры из Instagram (часть — стоп-кадры из видео, местами мягкие). Свежая съёмка студии и мастеров сильно поднимет сайт, особенно первый экран.

## Деплой (Vercel)

Настройки лежат в `vercel.json`: фреймворк отключён, Vercel запускает `node build.mjs --dist` и раздаёт папку `dist/` (только страницы и `assets/`, без исходников и `.claude/`). Каждый пуш в ветку — превью-ссылка, пуш в `main` — продакшн на https://ivanmarinalevant.vercel.app.

## Локальный просмотр

```bash
python3 -m http.server 8000
# http://localhost:8000/
```
